# Routine screenshots

Unretouched captures using the official Light SDK UI on an Android API 34
emulator at 1080 × 1240 / 420 dpi. Home and Data screens use the optimized 1.3.0 APK;
task editor and difficulty screens use the optimized 1.2.0 APK.
The English reward screens use the optimized 1.1.0 APK;
Chinese reward receipts use its debug build. The Chinese Data screens remain
captures from 1.0.2. First-use, Help, About and new-task type captures use
1.3.1 at 480 dpi to match the tested LP3 density; the other captures use 420 dpi. These are SDK
emulator screenshots, not photographs of physical Light Phone hardware.

All displayed habits, rewards, and records are neutral demonstration data from
a separate Android test user. The production app does not seed these examples.

- `welcome-en.png`, `welcome-zh.png`, `welcome-zh-tw.png`: the one-page first-use
  guide with Strength training, No alcohol, and No food after 8pm examples,
  plus Skip and Add a habit actions, from an empty test installation.
- `help-top-en.png`, `help-bottom-en.png`: the examples and detailed guide
  ending with the About entry.
- `about-en.png`, `about-zh.png`, `about-zh-tw.png`: plain-text version,
  author / X account, approved feedback email and source repository.
- `editor-en-0.png` through `editor-en-3.png`: the four type explanations in
  a new, unsaved task; no demonstration task is created.
- `help-en.png`: the guide reopened from Help, including additional reference
  sections and a thin scroll-position indicator.
- `home-en.png`: Help at the top right; separate Habits / To-dos tabs, left-aligned labels and
  underlines, square-bracket item counts, habit counts, scroll indicator,
  and local gold.
- `home-todos-en.png`: the separate pending to-do list; no scroll indicator
  when all items fit.
- `edit-en.png`: editing a positive habit with Hard difficulty and weekly counts.
- `difficulty-en.png`: Easy +5, Medium +10 and Hard +20 selection.
- `difficulty-zh.png`: Simplified Chinese difficulty selection.
- `difficulty-zh-tw.png`: Traditional Chinese difficulty selection.
- `rewards-en.png`: direct redemption list with affordable and disabled rewards.
- `reward-receipt-en.png`: reward name, amount spent, remaining gold, repeat
  count, Done, and Undo.
- `reward-history-en.png`: completed and undone redemptions with original costs.
- `reward-receipt-zh.png`: Simplified Chinese receipt.
- `reward-receipt-zh-tw.png`: Traditional Chinese receipt.
- `data-en.png`: explicit LightOS 582 file-transfer limitation, CSV export and
  local full backup controls.
- `data-zh.png`: Simplified Chinese Data screen.
- `data-zh-tw.png`: Traditional Chinese Data screen.

Use the home screenshot first for the Tool Library listing. Inspect the
Dashboard's image preview before submission; its precise crop rules have not
been checked. Keep private screenshots and actual user backups out of this
directory and out of the public repository.
